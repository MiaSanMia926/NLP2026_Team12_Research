# 预先规定的评价与统计分析定义

这是研究方法的分析约定，配合评价代码使用；不含项目时间表、成员管理或预设性能结论。C 已完成可独立核验的指标实现；标签规则待 A 复核，得分接口待 B/D 对接。

## 研究问题与主比较

- H1：同源复本如何改变答案、作答决定与风险？使用 no_replica / same_source_replica 基础题配对。
- H2：complete/missing/incorrect 条件下，B7 相对 B5 的风险—覆盖率折中如何？B7−B5 为预定主比较。
- H3：是否误删独立同义/互补支持？只在可靠谱系的面板测保留与错误案例，不把无变化一概当稳健。
- B6 单列 oracle 上限；不得读答案。无合法排序 score 的 B0–B3 不强行算 AURC。

## 训练、开发与测试隔离

先按基础题及派生 family 划分，再展开变体。train 拟合门控与预处理；dev 选特征/提示/阈值；test 只作冻结报告。pilot 看过的题不得重新进入正式 test。

主方法及三种消融分别拟合/dev 校准后冻结。建议 dev 以经验风险 10% 选择覆盖最高的完整 tie 组，并报告 dev n；这是经验选择，不提供风险保证。无非零可行 coverage 就如实报告。模型、提示、tokenizer、预算、采样、阈值与规则在查看 test 前留哈希。

## 主表

每个模型×任务×长度×metadata×重复条件独立报告：

1. 计划、成功、失败、可评分与作答数；coverage、selective risk 和分母。
2. 全题/已作答 EM/F1、不当作答/拒答。未知应答标签不纳入相应比例。
3. 冻结 dev 阈值的 test operating point，不仅靠大量拒答宣称安全。
4. 全候选齐全时的完整 RC/AURC；仅作答排序叫 partial，注明终点并只比共同区间。
5. 全部 tokens、额外调用、重试、延迟，缓存共享如何摊分。
6. B7−B5 配对差与 CI，以及复本变化、独立支持保留、人工引用审核。

受控任务与 QACC 事实外检分开。QACC 无合法应答标签时填 should_answer=null，不能按“冲突就应拒答”补真值。

## 统计实施

基础题为 cluster，同题所有条件随抽样；2,000 次配对 percentile bootstrap，seed=20261019，95% CI。风险/AURC 负差表示 B7 更低；coverage/质量分别解释。

重复抽样复制临时 pair ID；条件不齐报错，失败排除列出 ID 与各方法失败数量。无定义 replicate 不填零，报告有效数及不稳定区间。正式主分析按条件切片；若汇总多条件，必须事先指定等权基础题摘要并保留分条件表。

额外方法/多消融列为探索性；如需显著性检验先定义比较族和多重校正。本版只报告差值/CI，不自动生成显著性主张。CI 宽、跨零、无提升或负结果均如实保留。

## 对照与审计

自然长度和固定完整 prompt token 预算并列。B/D 使用真实 tokenizer 记录填充、位置、误差与额外调用，不能用字符数代替 tokens。

missing 保留 unknown；incorrect 预定义同源拆分/独立误合并及实际改动。模型不接收 condition_id 或错误类别等操控真值。gold 来源仅评价/oracle 可见。

去来源/去 unknown/去冲突三消融分别拟合校准，不套完整 B7 阈值。H3 与外检在看表现前定选题/排除规则；可靠新反证更新需单独定义前后答案，不能由错误反证条件替代。

A/D 对至少 50 个基础题或小集合全量双人独立复核，保留一致率和裁决。输出引用审查另外绑定 run_id，不从 EM 推断证据支持。每张图表保留数据、配置、代码与日志来源，开源/AI 用途如实披露。

examples 和软件测试不得混入真实结果，研究结论只来自真实、冻结、可复核输出。
