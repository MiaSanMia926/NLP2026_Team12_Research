## 研究方向

**来源依赖信息不完备时，检索增强问答的证据去重与选择性作答研究。**

关注多篇检索材料来自同一原始来源时，重复证据如何影响模型作答；进一步研究来源信息完整、缺失或错误条件下，证据去重与作答／拒答策略的可靠性。

计划围绕受控评价协议、轻量证据聚合与门控方法，以及风险—覆盖率和错误案例分析开展实验。
