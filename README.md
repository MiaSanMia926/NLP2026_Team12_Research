# NLP2026_Team12_Research

2026 年自然语言处理课程第 12 组，**Track C: Research**。

**题目：来源依赖信息不完备时，检索增强问答的证据去重与选择性作答研究。**

研究固定检索上下文下，同源转载、独立相似证据及来源信息缺失或错误如何影响答案与拒答。计划完成受控评价协议、轻量来源聚合与门控方法，以及风险—覆盖率和错误分析。

## 开始一次任务

1. 使用 [阶段任务模板](.github/ISSUE_TEMPLATE/stage_task.yml) 建 Issue，说明负责人、交付物和验收人。
2. 从最新 `main` 建任务分支，例如 `codex/data-pilot`；不要预建五条长期个人分支。
3. 在对应模块目录修改，提交并推送任务分支，创建 PR。
4. 交叉评审通过后合并到 `main`，完成后删除任务分支。
5. 更新贡献记录和对应里程碑。有实质变化才提交，不按 commit 数量评价贡献。

具体命令和网页操作见 [CONTRIBUTING.md](CONTRIBUTING.md)。本组采用 `main + 短期任务分支`，暂不额外设置 `develop`。

## 结果、复现和课程提交

主实验计划为一个冻结模型、B0–B5+B7 七方法、六主条件和两种长度设置；B6 单列 oracle。pilot 与正式测试分开，门控拟合、阈值选择和测试使用不同划分，详见实验协议。

代码、依赖和实验数据形成后，B/D 在此补充经验证的安装、小跑、完整运行和数据/模型获取步骤。当前不填写未经验证的运行命令。大日志保留访问方式和校验值，密钥、虚拟环境、模型权重和大缓存不入库。

课程材料由 E 按教师通知统一交到指定飞书文件夹；GitHub 用于协作与版本追溯。报告使用 ACL 官方模板，Research 最终正文 8 页；最终提交核对 [交付清单](deliverables/README.md)。
