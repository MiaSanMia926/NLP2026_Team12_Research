## 放行与提交

- [ ] 全部必做实验和分析完成，失败与局限如实披露。
- [ ] 每张表图可从冻结输出重算，日志可访问且哈希匹配。
- [ ] README 在独立环境完成安装和小跑；模型重新调用的波动有说明。
- [ ] 报告与 Slides 数字、案例、版本一致，8 页正文及引用规范合规。
- [ ] 五人确认实际贡献，披露开源/模型/AI 辅助使用。
- [ ] 代码包无密钥、个人凭据、虚拟环境、大权重和不允许再分发内容。
- [ ] E 统一上传课程飞书团队文件夹，D 复核文件、访问权限与版本。
- [ ] 保存提交时间、最终哈希、链接与回执；私人链接不公开入仓库。

12/15 是内部主体完成节点，12/16 起为独立验收缓冲，不能替代教师正式日期。详见 [里程碑](../docs/milestones.md)。
